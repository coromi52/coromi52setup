# AI SEO Meta Scorer

A Chrome extension for reviewing a page's title and meta description and generating editable AI suggestions.

**[Official product page and setup guide](https://artificialinteligenceai.com/ai/ai-seo-meta-scorer-chrome-extension/)** · **[Install from the Chrome Web Store](https://chromewebstore.google.com/detail/ai-seo-meta-scorer/fnfbaignkhmigehmgligghpmdmkeiebd)**

Published by [Artificial Intelligence AI](https://artificialinteligenceai.com/).

## What it does

- Reads the current page's H1 heading, title, and meta description when you run a scan.
- Generates suggested titles and meta descriptions using your configured AI provider.
- Lets you review and edit suggestions before using them.
- Shows character counters and Copy buttons.
- Provides settings for your AI provider and API key.

Useful for website owners, content editors, bloggers, and SEO practitioners who want to review metadata while browsing their pages.

## Install and use

1. Install **AI SEO Meta Scorer** from the Chrome Web Store using the link above.
2. Open Chrome's Extensions menu and pin the extension for easy access.
3. Open **Settings & API Keys** and configure a supported provider. See the official setup guide for available options.
4. Visit a public webpage you want to review.
5. Open the extension and select **Scan & Optimize This Page**.
6. Review the suggested title and meta description. Edit the text to match the page's content and your brand.
7. Use **Copy**, then paste the text into the appropriate title and meta description fields in your website's CMS.
8. Save or publish the changes in your CMS.

The extension supplies suggestions; it does not automatically update your website. Character counters help with editing, but search engines can display or rewrite titles and snippets differently.

## Provider setup and cost

The extension supports configuring your own AI provider/API key and includes a local offline option. Cloud providers may charge for usage separately. Check the current product guide and provider terms before choosing a configuration.

Do not post API keys in this repository or include them in screenshots.

## Troubleshooting

**A scan does not run:** Try a regular public webpage. Chrome restricts extensions on some browser pages and the Chrome Web Store.

**A provider request fails:** Check the selected provider, API key, model or endpoint settings where applicable, and any provider usage limits.

**The page has no description:** Some pages do not define a meta description. Review any generated text against the actual page before publishing.

**The website did not change after copying:** Paste the result into your CMS and save or publish it there.
